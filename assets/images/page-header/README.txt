Inner-page banner artwork

File in THIS folder:   assets/images/page-header/page-header-bg.png
(change the url() in assets/css/layout.css for another format or file name)

It sits behind the heading of every inner page (ผังเว็บไซต์, เกี่ยวกับ,
ติดต่อ, ...), cropped to cover the band and anchored to the BOTTOM, with a
white wash that fades out from the left (82% -> 0%) so the breadcrumb, title
and lead text stay readable while the artwork shows on the right.

The band is roughly 5:1 on a wide screen, so only the lower part of a 2:1
image is visible. Put the artwork along the BOTTOM edge of the file and keep
the upper half calm — the top is cropped away on wide screens.

Left third: keep it pale. Right two thirds: where decoration reads best.

  Suggested size:  2000 x 1000 px (2:1), under 900 KB
  Format:          PNG or JPG (rename the url() if you use .jpg)

Without the file the band shows the green gradient only — nothing breaks.
Confirm usage rights with the Office before launch.
