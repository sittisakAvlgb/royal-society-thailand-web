Featured knowledge band — background photo

Put the image in THIS folder:   assets/images/featured/

  featured-bg.png   <- this exact name (change the url() in assets/css/pages.css for another format)

Recommended: 2400 x 1200 px or larger, landscape, compressed for web
(PNG < 1 MB; JPG/WebP < 400 KB). A dark green overlay is applied in CSS so text
stays readable — a photo of the Royal Society building, library shelves or
manuscripts works well; avoid busy detail in the centre.

Confirm usage rights with the Office.
